# THE WORLD IN ONE DAY — news-image-20261120 (v1)

A classic print-broadsheet front page that sums up Friday 20 November 2026 in a single 1024×1024 image: 36 verified stories from that one day — three illustrated leads (the Kyiv bridge barrage, Cyclone Akvan's landfall in Odisha, and the deadlocked COP31 final day in Antalya) over compact regional columns covering Europe, the Middle East, Asia-Pacific, Africa, the Americas and science & climate. Every figure comes from the day's reporting (Reuters, AP, UN News, The Times, Sensor Tower estimates). The page is rendered by `render.py` (PIL, vendored Liberation fonts) and committed as `entry.png`; `main.py` is a stdlib-only copier that places it in the output directory.
